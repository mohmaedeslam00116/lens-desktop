# Competitive Feature Matrix Template

Standard schema for comparing software products and platforms across technical, commercial, and operational dimensions.

## Feature Matrix Table Schema

| Capability / Dimension | Competitor A | Competitor B | Competitor C | Reference Citations |
|:-----------------------|:-------------|:-------------|:-------------|:--------------------|
| **Core Architecture**  | Modular      | Monolithic   | Microservices| `[1]`, `[3]`        |
| **Deployment Models**  | Cloud SaaS   | Hybrid / VPC | Self-hosted  | `[2]`, `[5]`        |
| **Pricing Model**      | Usage-based  | Per-seat     | Tiered Flat  | `[4]`, `[6]`        |
| **API Availability**   | REST, gRPC   | GraphQL      | REST only    | `[7]`               |
| **Compliance**         | SOC2, HIPAA  | SOC2 Type II | ISO 27001    | `[8]`, `[9]`        |
| **Latency SLA**        | < 50ms (p99) | < 120ms      | Not stated   | `[10]`              |

## Evaluation Guidelines
- Use exact values, quotes, or metric units whenever possible.
- Avoid speculative claims; mark unverified capabilities as "Not Disclosed" or "Pending Verification".
- Always associate each cell with its corresponding primary-source citation index `[N]`.
