# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Researchers, knowledge workers, engineers, students, and decision makers who require autonomous, high-depth internet research, fact cross-checking, and structured multi-page syntheses without manual browsing fatigue.

## Product Purpose
An autonomous Deep Research desktop agent that investigates complex topics across 20+ web sources, filters noise, synthesizes cited reports, and provides real-time transparency through a modern split-screen studio interface.

## Positioning
An open, self-contained flagship desktop application (crafted to the standards of Antigravity, Cursor, and Linear) that operates with local execution, BYOK encryption, DuckDuckGo and Tavily retrievers, and direct document-level collaboration.

## Operating Context
Desktop environment (Electron) running on Windows/macOS with a local FastAPI sidecar. Used for deep analytical reading, technical investigations, market research, and report generation.

## Capabilities and Constraints
- Autonomous research planning (generating sub-queries, scraping web pages, evaluating evidence).
- Real-time WebSocket streaming of agent reasoning, sub-queries, source URLs with favicons, and section drafting.
- Three-pane Studio Workspace:
  - Left: Activity rail & Research history tree.
  - Center: Interactive Research Canvas with floating Table of Contents and citation cards.
  - Right: Agent Command Inspector & Copilot Follow-up Chat side-by-side with the document.
- Multi-format document exports (PDF, Microsoft Word DOCX, Markdown).
- Native bilingual Arabic & English with bidirectional RTL/LTR layout.
- Secure local key storage via Electron safeStorage.

## Brand Commitments
- Name: Deep Research AI | الباحث العميق الذكي
- Design Language: Obsidian Agent Studio (inspired by Linear, Cursor, Raycast, and Antigravity).
- Impeccable Anti-Slop Discipline: No nested cards inside cards, no rainbow gradient text, no emoji icons (crisp SVGs only), no modal traps for reading/chatting, restrained color palette, and micro-border depth.

## Product Principles
1. Complete agent transparency: users can inspect every reasoning step and visited domain.
2. The report is a living canvas, not a chat bubble stream.
3. Restrained high-density utility: tools disappear into the task.
4. Privacy and independence: zero telemetry, zero mandatory cloud accounts.
